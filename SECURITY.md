# security policy

bloc is in pre-release development. No version is currently supported for
production authentication. Security fixes target the default branch until a
release support policy is established.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, or personal
data. Use [private vulnerability reporting](https://github.com/rodalladea/bloc/security/advisories/new)
or email Rodrigo Dalla Dea at [rodalladea@catap.io](mailto:rodalladea@catap.io). Include affected
revision, impact, reproduction using synthetic data, and any proposed mitigation.

If GitHub private reporting is unavailable, use the email address above. Rodrigo
Dalla Dea (@rodalladea) is currently the sole security contact.

Maintainers coordinate triage, fixes, advisories, and disclosure with reporters.
There is no guaranteed response SLA at this stage. Do not test against systems
without authorization.
